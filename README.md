## Tauri Asset Extractor

This tool was made for anyone wanting to get Tauri assets <br> But have to deal with CLI's
So this GUI version is useful if you dont want to download Rust at all.

## Download where?
Download the latest exe from the releases tab area.

## Available for..

* **Windows** (Yes)
* **MacOS** (No)
* **Linux** (No)

## However..

You can compile from source soooo here's the things you need..

[Rust Language Itself](https://rustup.rs/)

After that make sure you have [GIT](https://git-scm.com/install/) installed. (In order to clone the thing)

Then clone this repository and then open a terminal in the project folder:

```bash
git clone https://github.com/RizsimStudiosOfficial/Tauri-GUI-Asset-Extractor
cd Tauri-GUI-Asset-Extractor/src-tauri
```

then just build with this command here

```bash
cargo tauri build
```

And you should be all set! - Rizsim Studios
